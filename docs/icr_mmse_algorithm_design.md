# 不完美 CSI 下联合信道修正与 MMSE 深度展开的水声 OFDM 均衡算法

本文按当前实现同步：修正网络采用 `14(2B+1)+5` 通道反馈，均衡层采用预条件 Richardson 子步与局部 QPSK logits 校准。主配置为 `complex64`、对角噪声权重；RTX 4080 的训练数据准备与 batch/cache 设置见 [运行说明](icr_mmse.md#6-验证与运行) 和 [训练性能实测](icr_mmse_training_performance.md)。

## 1. 研究背景

### 1.1 水声 OFDM 双选择信道的均衡问题

水声通信信道具有明显的多径传播和时变特征。多径时延使信道在频率上呈现选择性，传播环境和收发端相对运动引起的时变则使信道在时间上呈现选择性。当两种效应同时存在时，接收机面对的是时间—频率双选择信道。

OFDM 将宽带传输划分为多个子载波。在一个 OFDM 符号内近似时不变、保护间隔足够且同步理想的条件下，频域信道可以近似为对角矩阵，每个子载波主要受到自身信道响应的影响。水声信道的快速变化会破坏这种近似，使一个发射子载波的能量扩散到其他接收子载波，形成子载波间干扰（inter-carrier interference，ICI）。

因此，双选择条件下的均衡需要同时处理目标子载波和邻近甚至更远子载波之间的耦合。频域信道矩阵的非对角元素具有明确的物理作用，仅关注对角频率响应难以完整描述接收信号。

### 1.2 不完美 CSI 对均衡的影响

实际接收机只能根据有限导频、含噪观测以及选定的信道模型获得信道状态信息（channel state information，CSI）。初始估计误差可能来自导频观测噪声、时变跟踪不足、有限基展开、延迟支撑截断和接收机模型失配。这些误差往往具有时间、频率或路径结构，不能简单理解为每个矩阵元素上相互独立的扰动。

CSI 误差直接改变均衡器采用的观测模型。一方面，错误的耦合系数会影响 ICI 消除和符号估计；另一方面，导频列的误差会造成已知导频贡献消除不准确，使原本已知的信号成为额外干扰。初始 CSI 一旦固定，这些误差可能在后续多次检测中持续存在。

因此，本研究关注的问题是：在保留接收机初始估计的基础上，能否利用均衡过程中逐渐形成的软符号信息，对影响检测的信道误差进行有约束的修正。

### 1.3 CSI 修正与符号检测之间的相互依赖

较准确的 CSI 有助于获得可靠的符号判决；可靠的符号估计又能为信道修正提供额外约束。二者具有天然的闭环关系，但这一关系同时包含错误传播风险。

在低信噪比或初始 CSI 偏差较大时，软判决可能不准确。若将错误判决当作可靠符号用于信道修正，修正网络可能把符号错误写入信道，使下一轮均衡进一步恶化。此外，接收残差同时包含信道误差、符号误差、噪声及模型失配，残差降低并不必然意味着物理 CSI 更准确。

算法需要同时解决三个问题：为信道修正提供与矩阵元素严格对应的反馈信息；区分软判决的不同可靠程度；让 CSI 修正与最终检测目标在训练中协调，而不是单独追求某一个中间量。

## 2. 研究意义

### 2.1 将 CSI 作为均衡过程中可更新的状态

本研究把 CSI 从固定输入扩展为联合迭代状态，使均衡过程能够依据当前观测和符号分布持续调整信道解释。这样，信道估计与符号检测之间的信息交互被明确写入算法结构，而不是只依赖一个网络在内部隐式抵抗模型误差。

这一设计的意义在于，可以逐层观察信道变化、符号概率变化以及两者之间的关系，为分析不完美 CSI 下的均衡行为提供更清晰的物理对象。

### 2.2 让信道修正直接服务于通信目标

信道归一化均方误差（normalized mean square error，NMSE）衡量信道矩阵的重建精度，误码率（bit error rate，BER）衡量最终通信性能。两者相关，但并不等价：不同矩阵方向上的误差对符号判决的影响不同，某些 NMSE 改善也可能主要发生在当前数据未激发的方向上。

因此，本算法以检测目标为主，同时使用物理 CSI 监督约束修正结果。其目的在于兼顾通信有效性与信道解释，使学习到的修正既有利于符号检测，又具有接近参考信道的明确目标。

### 2.3 融合物理模型与学习先验

MMSE 深度展开保留信道算子、导频消除、匹配滤波和有色噪声处理的物理结构；小型修正网络学习难以完全解析建模的结构化估计误差。模型部分规定信息应如何流动，学习部分补充有限模型无法准确表达的规律。

显式构造残差与软符号的相关特征，可以减少网络自行寻找载波对应关系和学习基础复数运算的负担。共享卷积进一步把相邻频率位置可能具有相似误差规律这一先验引入修正过程。

### 2.4 在有限参数规模下形成可分析的闭环

修正网络在所有联合层之间共享参数，均衡层则使用独立参数适应不同迭代阶段。带状增量限制需要学习的修正范围，完整基础矩阵保留已有的频域耦合信息。

这种结构能够控制可训练参数规模，并使修正带宽、展开深度、软可靠性和训练目标之间的关系具有明确含义。研究预期是获得有效、可解释且可复现的联合估计检测机制；实际性能、计算效率和稳定性仍取决于具体信道与训练结果。

## 3. 算法设计

算法暂称为 **ICR-MMSE-Net**。一个联合迭代层由三层 CSI 修正网络和一个 MMSE 深度展开均衡层组成。整体遵循“当前软状态与残差 → 局部 CSI 修正 → 更新后的信道均衡 → 新的软状态”的顺序。

下文统一将接收机原始估计记为 $H_0$。修正网络跨层共享参数，均衡层参数逐层独立；初始数据概率均匀，参考信道和真实数据符号只用于训练监督。

### 3.1 信号模型与基本符号

#### 3.1.1 基本符号

| 符号 | 含义与维度 |
|---|---|
| $N$ | 物理 FFT 子载波数，当前为 1024 |
| $\mathcal D,\mathcal P,\mathcal Z$ | 数据、导频、空载波集合，构成完整网格的互斥划分 |
| $N_D,N_P$ | 数据和导频数量，当前为 512、128 |
| $S_D\in\{0,1\}^{N\times N_D}$ | 从压缩数据向量散射到物理网格的选择矩阵 |
| $x_D\in\mathbb C^{N_D}$ | 未知数据符号 |
| $x_K\in\mathbb C^N$ | 已知导频，其他位置为零 |
| $x=S_Dx_D+x_K$ | 完整发射频域符号 |
| $y\in\mathbb C^N$ | 一个 D 块的频域接收观测 |
| $H_{\rm ref},H_0,H_t\in\mathbb C^{N\times N}$ | 参考信道、原始初始估计、第 $t$ 次修正后的信道 |
| $C\in\mathbb C^{N\times N}$ | 单位 RF 噪声对应的接收协方差 |
| $\sigma_{\rm RF}^2$ | 当前样本 RF 噪声方差，$R_n=\sigma_{\rm RF}^2C$ |
| $T$ | 联合迭代层数，起始值为 8 |
| $B,K=2B+1$ | 修正半带宽与偏移通道数量，起始为 16、33 |
| $p_{t,j,a}$ | 第 $t$ 层数据位置 $j$ 属于星座点 $a$ 的概率输出 |
| $\mu_t,v_t\in\mathbb C^N\times\mathbb R_+^N$ | 完整网格上的软均值与软方差 |
| $E_t\in\mathbb C^{N\times K}$ | 累积带状信道增量 |
| $\mathcal B(E_t)$ | 将带状表示散射为完整矩阵的算子 |

批次、SNR、信道类型和 D1/D2 索引在公式中省略。D1/D2 使用相同参数独立处理；原始 CSI 的生成可以共享整帧系数，但本版不引入两块之间的额外神经消息传递。

#### 3.1.2 接收模型

对一个数据块使用

$$
y=H_{\rm ref}x+\xi+n,\qquad
\mathbb E[n]=0,\quad \mathbb E[nn^{\rm H}]=R_n.
\tag{1}
$$

$\xi$ 表示当前块参考线性模型没有解释的物理残差，例如块间泄漏和通带链路中的其他失配。它不预设为独立白高斯噪声，也不在推理时提供其样本真值。

参考信道表示未能解释的接收链影响归入 $\xi$。在未证明这些影响可忽略前，不将式（1）简化为严格无模型失配的 $y=H_{\rm ref}x+n$。

#### 3.1.3 信号配置

| 项目 | 数值或约定 |
|---|---|
| 帧结构 | P1–D1–D2–P2 |
| FFT / CP / FFT 提前量 | 1024 / 384 / 32 个采样 |
| 基带 / 通带采样率 | 6 kHz / 96 kHz |
| 载频 | 14 kHz |
| 调制 | 单位能量 QPSK |
| 数据 / 导频数量 | 每 D 块 512 / 128 |
| SNR | 0、5、10、15、20、25、30 dB |
| 整帧 DPSS 时间长度 | 5632 |
| DPSS 时间基数 $Q$ / 延迟支撑 $L$ | 34 / 736 |
| DPSS 半带宽 | 15.686274509803921 Hz |

本设计采用以下 QPSK 映射：类别 $c=2b_0+b_1$，00、01、10、11 依次对应 $(1+j),(1-j),(-1+j),(-1-j)$ 除以 $\sqrt 2$。训练、硬判决、BER 和未来 LLR 转换必须共用这一映射。

### 3.2 初始 CSI 与监督信息边界

#### 3.2.1 原始信道的定义

令 $\Theta_{\rm raw}\in\mathbb C^{Q\times L}$ 为接收机获得的整帧原始估计系数，$\mathcal A_d$ 为第 $d$ 个数据块的固定 DPSS—频域矩阵映射，则

$$
H_0^{(d)}=\mathcal A_d(\Theta_{\rm raw}),\qquad d\in\{D1,D2\}.
\tag{2}
$$

主方法不把原始系数、参考投影或其误差另行作为网络输入。DPSS 用于定义和重建初始估计，后续带状矩阵修正不强制留在该 DPSS 子空间。

这使模型可以从实际观测学习部分子空间外失配，但其恢复能力必须由实验检验，不能由“存在参考监督”直接推出。

#### 3.2.2 避免目标信息进入模型输入

如果初始 CSI 通过以下方式混入当前样本的参考信道：

$$
H_{\rm mix}=\alpha H_{\rm raw}+(1-\alpha)H_{\rm ref}.
$$

若 $H_{\rm raw}\in\mathcal S$，对其正交补投影 $P_\perp$ 有

$$
P_\perp H_{\rm mix}=(1-\alpha)P_\perp H_{\rm ref}.
\tag{3}
$$

因此存在直接的目标比例分量。隐藏 $\alpha$、删除某一路 $H_{\rm mix}$ 输入或对网络停止梯度，都不能消除经残差、均衡状态和统计量传递的信息。仅投影到 $\mathcal S$ 也保留子空间内的混合。

本算法采用式（2）的原始接收机估计，参考信道只参与损失计算，从输入来源上排除上述直接缩放通道。

#### 3.2.3 输入白名单

允许：$y,H_0,x_K$、物理位置与三类掩码、$\sigma_{\rm RF}^2,C$。本设计采用已知噪声参数假设；若实际接收机使用噪声估计值，其误差需作为模型适用条件考虑。

不允许：当前样本的 $H_{\rm ref}$、真实数据符号、真实误差、$\alpha$、参考投影、真实 NMSE、实际 SNR 诊断量，以及由这些量构造的逐样本代理。

模型只接收含噪观测 $y$，不同时接收干净信号与噪声实现。初始 CSI、接收观测及其归一化均不得使用当前样本的参考信道或真实数据符号。

### 3.3 联合估计的目标与可辨识性

#### 3.3.1 一个观测不能唯一确定完整信道

即便 $x$ 已知，单块模型 $y=Hx$ 只给出 $N$ 个复约束，而完整 $H$ 有 $N^2$ 个复未知量。若 $Zx=0$，则 $H$ 与 $H+Z$ 在该符号向量上的观测相同。

带状修正降低了自由度，但一行仍可能含 $2B+1$ 个待修正项，单行观测通常不能唯一确定它们。已知导频改善约束，却不会自动使问题完全可辨识。

本算法依赖三个先验来源：原始接收机估计、跨频率共享的信道误差结构，以及训练集学习到的统计规律。不能将网络输出解释为从单块残差中无条件恢复真实 $H$。

#### 3.3.2 CSI 目标与检测目标的关系

一个解释性联合目标可写为

$$
\mathcal J(H,x_D)=
\|y-H(S_Dx_D+x_K)\|_{R_n^{-1}}^2
+\lambda_{\rm ch}\mathcal R(H,H_0)
-\log p(x_D),
\tag{4}
$$

并约束 $H-H_0$ 具有指定局部支撑。这里 $\mathcal R$ 表示信道先验，不声称实际 CNN 恰好是某个已知正则项的近端算子。

实际方法以监督损失训练展开网络。式（4）用于说明交替利用观测一致性、信道先验和离散符号先验的动机，而不是宣称网络严格求解了该 MAP 问题。

#### 3.3.3 双目标之间可能冲突

$$
r_t=(H_{\rm ref}-H_t)x+H_t(x-\mu_t)+\xi+n.
\tag{5}
$$

残差同时混合了 CSI 误差、符号误判、物理失配和噪声。若网络把后面三项写入 $H_t$，残差可能下降而 CSI NMSE 上升。

因此主结果必须同时报告 BER 与物理 CSI NMSE，并以训练外观测一致性、导频消除误差等诊断解释冲突。不能把残差更小直接等同于信道更真实。

### 3.4 软符号状态与带状信道表示

#### 3.4.1 软符号定义

对数据位置 $j\in\mathcal D$，

$$
\mu_{t,j}=\sum_{a\in\mathcal S}p_{t,j,a}a,\qquad
v_{t,j}=\sum_a p_{t,j,a}|a-\mu_{t,j}|^2.
\tag{6}
$$

单位能量 QPSK 下，$v_{t,j}=1-|\mu_{t,j}|^2$。数值实现只将舍入产生的极小负值截为零；不能用任意截断掩盖错误概率。

导频位置使用 $\mu_{t,j}=x_{K,j},v_{t,j}=0$，空槽使用零均值与零方差。网络概率是用于反馈的预测分布，不预设为精确或校准的贝叶斯后验。

初始化为 $p_{0,j,a}=1/4$，因此数据均值为零、方差为一。初始完整均值就是 $x_K$。

#### 3.4.2 局部增量定义

令 $d=-B,\ldots,B$、$j=k+d$，有效性为 $m_{k,d}=1_{\{0\le j<N\}}$。定义

$$
[\mathcal B(E)]_{k,j}=
\begin{cases}
E[k,j-k],& |j-k|\le B,\\
0,&\text{其他}.
\end{cases}
$$

使用

$$
H_t=H_0+\mathcal B(E_t),\qquad E_0=0.
\tag{7}
$$

这里的距离是物理 FFT 位置距离；不绕回边界，不将数据载波压紧后计算邻域。虽然 FFT 算子具有周期结构，本设计使用保护带条件下的非环绕局部支撑，边界处通过有效性掩码处理。

默认允许所有有效带内元素接受 CSI 监督，包括数据列、导频列和空槽列。空槽列不会影响当前块接收预测，因此必须另报数据列、导频列与空槽列的 NMSE，避免总 NMSE 的改善主要来自不影响检测的元素。

#### 3.4.3 不生成逐层完整矩阵的计算

$$
H_tz=H_0z+\mathcal B(E_t)z,\qquad
H_t^{\rm H}r=H_0^{\rm H}r+\mathcal B(E_t)^{\rm H}r.
\tag{8}
$$

带状部分通过索引乘积及累加实现；伴随必须使用共轭并累加到正确发射列。基础矩阵仍完整保留，所以主方法的总体运算不是 $O(NB)$。

#### 3.4.4 修正范围的不可突破下界

令 $M_B$ 为允许更新的位置掩码，则即使带内修正完全正确，也有

$$
\min_{\operatorname{supp}(\Delta)\subseteq M_B}
\|H_0+\Delta-H_{\rm ref}\|_F^2
=\|(1-M_B)\odot(H_0-H_{\rm ref})\|_F^2.
\tag{9}
$$

右侧是该支撑下的 oracle 误差下界，不需要训练网络即可计算，但只能作为监督诊断，不能进入推理。若下界已经很高，应先质疑局部支撑假设，而不是无止境增加网络层数。

### 3.5 三层 CSI 修正网络

#### 3.5.1 固定尺度归一化

每个 D 块由输入 $H_0$ 计算

$$
s=\max\left(\sqrt{\|H_0\|_F^2/N},\epsilon_s\right),\quad
\widetilde H_t=H_t/s,\quad
\widetilde y=y/s,\quad
\widetilde\sigma^2=\sigma_{\rm RF}^2/s^2.
\tag{10}
$$

尺度只由允许的原始输入确定，所有层保持相同。符号均值与方差不随接收增益缩放。修正网络使用归一化残差 $\widetilde r_t=\widetilde y-\widetilde H_t\mu_t$。

研究默认 $\epsilon_s=10^{-12}$，近零能量样本需记录并单独诊断。不得使用参考信道能量或真实 SNR 归一化。

采用固定 $s$ 避免网络通过改变当前 $H_t$ 的范数改变自身坐标系。每轮依赖 $H_t$ 的检测特征仍重算，不能据此沿用旧的匹配滤波或导频消除。

#### 3.5.2 逐矩阵元素的 14 维特征与行级残差

对每个有效 $(k,d)$，$j=k+d$，按以下顺序构造实数特征：

| 分量 | 通道数 | 作用 |
|---|---:|---|
| $\operatorname{Re/Im}\widetilde H_0[k,j]$ | 2 | 初始锚点 |
| $\operatorname{Re/Im}\widetilde H_t[k,j]$ | 2 | 当前信道状态 |
| $\operatorname{Re/Im}\mu_{t,j}$ | 2 | 与发射列严格对应的软符号 |
| $v_{t,j}$ | 1 | 该发射列的预测不确定度 |
| $\operatorname{Re/Im}(\widetilde r_{t,k}\mu_{t,j}^*)$ | 2 | 显式残差相关项 |
| $\operatorname{Re/Im}(\widetilde H_t[k,j]v_{t,j})$ | 2 | 显式方差调制项 |
| 数据、导频、有效性掩码 | 3 | 区分符号类型和填充 |
| 合计 | 14 | 每个偏移 |

无效位置所有偏移特征置零；不得让索引夹取后的边界值泄漏到填充位置。空槽掩码可由 `null=valid-data-pilot` 恢复。当前接收行的复残差 $\widetilde r_{t,k}$ 单独保存一次，其逐偏移版本可由行级残差乘有效性掩码恢复。

将 $K$ 个偏移拼成通道，再加入行级残差的实、虚部，以及以下三个逐接收行特征：

$$
\log(1+\widetilde\sigma^2),\quad
\log(\max(C_{kk},\epsilon_C)),\quad k/N.
\tag{11}
$$

偏移张量形状为 $[\text{batch},N,K,14]$，行级残差形状为 $[\text{batch},N,2]$，卷积输入为 $[\text{batch},14K+5,N]$。默认 $B=16$ 时为 467 个实数输入通道。式（11）取 $\epsilon_C=10^{-20}$，用于合法正对角元素的数值保护，不替代协方差正定性检查。

当前布局将旧 564 通道表示中的重复残差与冗余空槽掩码改为可恢复表示。第一层卷积权重形状随之改变，旧布局检查点须重新训练。

这一设计解决了感受野不足以定位 $\mu_{k+d}$ 的问题，但不声称卷积能看到完整 $33\times33$ 矩阵邻域。网络在行方向仍只直接访问 5 个相邻接收行。

#### 3.5.3 物理特征的推导和限制

固定当前软分布 $q(x)$，令其均值为 $\mu$、协方差为 $V$，定义

$$
\mathcal Q(H)=
(y-H\mu)^{\rm H}R_n^{-1}(y-H\mu)
+\operatorname{tr}(R_n^{-1}HVH^{\rm H}).
\tag{12}
$$

对 $H^*$ 的 Wirtinger 偏导为

$$
\frac{\partial\mathcal Q}{\partial H^*}
=-R_n^{-1}r\mu^{\rm H}+R_n^{-1}HV.
\tag{13}
$$

当采用 $V=\operatorname{diag}(v)$ 的独立符号近似且 $R_n=\sigma^2I$ 时，负梯度的 $(k,j)$ 元素正比于

$$
r_k\mu_j^*-H_{kj}v_j.
\tag{14}
$$

这解释了两个显式乘积的意义。它们不等于完整有色噪声情形下的精确梯度；后者涉及 $R_n^{-1}r$ 和 $R_n^{-1}H$。相关噪声、符号相关性、模型残差和随 $H$ 变化的协方差均会改变该解释。

主修正网将这些量作为物理启发输入，学习更新方向与先验约束，不将式（14）直接当作确定的最优更新。均衡模块使用配置选择的对角噪声权重或完整有色噪声处理。

#### 3.5.4 三层网络、门控和更新

$$
Z_1=\operatorname{SiLU}(\operatorname{Conv}_{3}^{14K+5\to32}(F_t)),
$$
$$
Z_2=\operatorname{SiLU}(\operatorname{Conv}_{3}^{32\to32}(Z_1)),
$$
$$
[D_t^{\rm R},D_t^{\rm I},a_t]
=\operatorname{Conv}_{1}^{32\to3K}(Z_2).
\tag{15}
$$

三层均为步长 1，前两层零填充 1，最后一层无额外填充，不使用池化。令 $D_t=D_t^{\rm R}+jD_t^{\rm I}$，$g_t=\operatorname{sigmoid}(a_t)$。

采用矩阵元素的初始 RMS 尺度 $s_H=s/\sqrt N$ 恢复物理量：

$$
E_{t+1}=E_t+\eta_t s_H\,(g_t\odot D_t)\odot m,\qquad
\eta_t=\operatorname{sigmoid}(\beta_t).
\tag{16}
$$

全部卷积参数跨 $t$ 共享，$\beta_t$ 逐层独立。默认 $\eta_t=0.1$，即 $\beta_t=\log(0.1/0.9)$。

复数修正输出对应的头部权重与偏置初始化为零；门控头和前两层卷积沿用 PyTorch `Conv1d` 默认初始化，门控经 Sigmoid 保持有限非零。若把门控或阻尼也设为精确零，会使修正分支出现梯度锁死风险。

零修正头使第一步主要更新输出头，上游特征层和门控的梯度可能初始为零，随后在修正头非零时恢复。这是初始化行为，不应误判为整个模块无法训练。

#### 3.5.5 可靠性解释的边界

Sigmoid 门控限制的是乘数，不限制 $D_t$ 的幅值，也不保证修正方向正确。$g_t,D_t,\eta_t$ 之间还存在尺度补偿，门控值不能未经校准就解释为“该信道元素正确的概率”。

低方差可能来自过度自信的错误判决。应通过置信度分组和错误反馈恶化率检查可靠性机制，而不能仅展示一张门控热力图。

软门控与阻尼属于更新控制机制，不依赖参考真值选择当前层是否接受修正。

### 3.6 MMSE 深度展开均衡层

#### 3.6.1 从 LMMSE 正规方程到展开特征

当前信道完成修正后，令

$$
y_{D,t+1}=y-H_{t+1}x_K,\qquad A_{t+1}=H_{t+1}S_D.
\tag{17}
$$

令噪声逆作用为 $\mathcal W$：主配置 `model.noise_mode="diagonal"` 使用 $\mathcal W=\operatorname{diag}(C)^{-1}$；`"full"` 对照使用 $\mathcal W=C^{-1}$。前者保留各接收频点噪声功率，对协方差非对角项作近似。在单位能量、独立、零均值数据先验下，相应线性目标为

$$
\mathcal L_{\rm lin}(z)=
(y_{D,t+1}-A_{t+1}z)^{\rm H}\mathcal W(y_{D,t+1}-A_{t+1}z)
+\sigma_{\rm RF}^2 z^{\rm H}z.
\tag{18}
$$

其正规方程为

$$
\left(A_{t+1}^{\rm H}\mathcal W A_{t+1}
+\sigma_{\rm RF}^2I\right)z
=A_{t+1}^{\rm H}\mathcal W y_{D,t+1}.
\tag{19}
$$

在完整模式下，式（18）由使用 $R_n=\sigma_{\rm RF}^2C$ 的目标乘以常数得到；对角模式对应以 $\sigma_{\rm RF}^2\operatorname{diag}(C)$ 近似噪声协方差。因而不需要先将每项再除以 RF 方差。对非单位符号能量 $E_s$，正则项为 $\sigma_{\rm RF}^2/E_s$，但本版固定 $E_s=1$。

正规方程中的必要计算是匹配滤波与正规算子作用。常规梯度更新会出现

$$
z^+=z-\delta\left[
\left(A^{\rm H}\mathcal W A+\sigma_{\rm RF}^2I\right)z
-A^{\rm H}\mathcal W y_D\right].
\tag{20}
$$

本算法保留式（20）的物理信息流，以学习型非线性映射生成离散星座分布，而不是逐层显式求解式（19）。它不等于每层精确执行一次闭式 LMMSE，也不自动继承固定线性迭代的收敛性。离散 QPSK 的精确非线性 MMSE 后验均值与 LMMSE 也不是同一个对象。

#### 3.6.2 全局算子的计算

先在数据维度定义

$$
b_{t+1}=A_{t+1}^{\rm H}\mathcal W y_{D,t+1},
$$
$$
q_{t+1}=
A_{t+1}^{\rm H}\mathcal W(A_{t+1}\mu_{D,t}),
\quad \mu_{D,t}=S_D^{\rm H}\mu_t.
\tag{21}
$$

计算时可以用完整 $H$ 算子及数据掩码等价实现，随后将 $b,q$ 散射回 $N$ 个物理位置，非数据坐标置零。

不能把 $q$ 换成局部窗口内的 $H_{\rm local}^{\rm H}H_{\rm local}\mu_{\rm local}$：那会丢掉窗外数据的影响，改变已确定的完整基础耦合设计。

所有量均使用更新后的 $H_{t+1}$，不能仅替换网络的 CSI 通道而继续使用旧的 $y_D,b,q$。

#### 3.6.3 噪声模式与分解成本

对角模式按 $(\mathcal W u)_k=u_k/\max(\operatorname{Re}C_{kk},10^{-20})$ 逐元素计算，省去协方差 Cholesky 和三角求解。完整模式对固定的 Hermitian 正定 $C$ 使用

$$
C=LL^{\rm H},\qquad C^{-1}u=L^{-{\rm H}}(L^{-1}u).
\tag{22}
$$

完整模式调用三角求解，不显式形成 $C^{-1}$。同一设备、精度和协方差内容下，固定 $L$ 在同一模型内跨层、批次和轮次缓存；每次算子作用仍有向量求解成本。缓存仅保留一份快照与因子，协方差或设备、精度变化时重建，不进入检查点。

两种模式均保留完整信道耦合，预条件器和 CSI 网络噪声输入均使用相同的 $C$ 对角。RF 方差独立参与正则项，不触发单位协方差重分解。构造器省略 `noise_mode` 时仍取 `full`；当前统一 JSON 配置显式指定 `diagonal`。

式（22）要求 $C$ 为 Hermitian 正定矩阵；对奇异或不定协方差不能直接使用该分解。

#### 3.6.4 预条件子步、展开特征与窗口

均衡器在原物理尺度计算式（21），使用当前信道的加权列能量进行对角预条件。对数据位置 $j$ 定义

$$
e_{t+1,j}=\max\left(\sum_k\frac{|H_{t+1}[k,j]|^2}{\max(\operatorname{Re}C_{kk},10^{-20})},10^{-20}\right),\quad
d_{t+1,j}=\max(e_{t+1,j}+\sigma_{\rm RF}^2,10^{-20}),
$$
$$
z_{t+1,j}=\mu_{D,t,j}+\omega_t
\frac{b_{t+1,j}-q_{t+1,j}-\sigma_{\rm RF}^2\mu_{D,t,j}}{d_{t+1,j}},\qquad
\omega_t=2\operatorname{sigmoid}(\alpha_t).
\tag{23}
$$

这是对式（19）的可学习预条件 Richardson 子步。$e$ 在完整噪声模式下仍只作为对角预条件近似，正规作用 $q$ 保留所选 $\mathcal W$ 的全部作用。$\alpha_t$ 初值为0，因此 $\omega_t$ 初值为1。

将数据向量散射回完整物理网格，非数据位置置零。每个物理位置构造14个实数特征：

| 分量 | 通道数 |
|---|---:|
| $\operatorname{Re/Im}\mu_{D,t,j}$ | 2 |
| $\operatorname{Re/Im}z_{t+1,j}$ | 2 |
| $\operatorname{Re/Im}(b_{t+1,j}/d_{t+1,j})$ | 2 |
| $\operatorname{Re/Im}(q_{t+1,j}/d_{t+1,j})$ | 2 |
| $v_{t,j}$ | 1 |
| $\log(1+\sigma_{\rm RF}^2/e_{t+1,j})$ | 1 |
| 数据、导频、空槽掩码 | 3 |
| 居中载波坐标 $\kappa_j=(j-(N-1)/2)/N$ | 1 |

设上述向量为 $\varphi_{t,j}\in\mathbb R^{14}$，窗口输入为

$$
f_{t,w}=\operatorname{flatten}([\varphi_{t,j}]_{j\in w})\in\mathbb R^{14W}.
\tag{24}
$$

窗口宽 $W=32$、中心宽 $S=16$。中心起点为 $0,16,\ldots$，对应窗口覆盖起点前8个位置到起点后23个位置，越界特征全部零填充。所有中心依次覆盖完整网格，数据位置参与分类与损失。默认输入维度为448；式（10）的固定归一化用于 CSI 修正网络，均衡特征按式（23）的当前列尺度归一化。

#### 3.6.5 学习型更新与软输出

每层、每窗口计算

$$
h_{t+1,w}=\tanh(W_{t,1}f_{t,w}+b_{t,1}),
$$
$$
\ell_{t+1,w}
=\operatorname{reshape}(W_{t,2}h_{t+1,w}+b_{t,2},S,4).
\tag{25}
$$

隐藏维度为48，输出为每窗口中心区域的 $16\times4$ 个 logits。层间参数独立，同一层所有窗口共享参数；隐藏映射沿用 PyTorch `Linear` 默认初始化，分类头权重与偏置零初始化。将唯一中心输出拼为全局局部校准量 $\ell_{t+1,j,a}$，每个物理载波只归属一个中心。

QPSK 距离 logits 与局部校准量相加后产生概率。令 $\bar v_t=N_D^{-1}\sum_{j\in\mathcal D}v_{t,j}$，则

$$
\tau_{t+1,j}=\operatorname{clip}(\exp(\gamma_t),0.01,100)
\max\left(\frac{\sigma_{\rm RF}^2}{e_{t+1,j}}
+\operatorname{softplus}(u_t)\bar v_t,10^{-5}\right),
$$
$$
p_{t+1,j,a}=\operatorname{softmax}_a\left(
-\frac{|z_{t+1,j}-a|^2}{\tau_{t+1,j}}+\ell_{t+1,j,a}\right),\qquad j\in\mathcal D.
\tag{26}
$$

$\gamma_t$ 初值为0，$u_t$ 初值为 $\log(\exp(0.1)-1)$，与式（23）的 $\alpha_t$ 构成每层三个独立标量。当前层间软状态由均值和方差传递，隐藏映射逐层重算，式（26）直接给出下一层概率。非数据位置概率置零，其均值、方差按第3.4节固定。去不确定度消融将反馈及均衡特征中的方差置零，并去掉 $\bar v_t$ 的影响。

#### 3.6.6 下一层反馈与最终判决

由式（6）计算 $\mu_{t+1},v_{t+1}$ 后进入下一层。训练和推理均不在中间层做硬判决。

本研究以 BER 为主，最终使用比特边缘判决：

$$
\widehat b_{j,\ell}
=\arg\max_{b\in\{0,1\}}\sum_{a:\,b_\ell(a)=b}p_{T,j,a}.
\tag{27}
$$

在当前 QPSK 映射下，等价于软均值实部和虚部的符号判决。精确相等时固定判为 0，保证可复现。

若另报 SER，使用四类联合 $\arg\max_a p_{T,j,a}$ 并单独标记。它与两次边缘判决可能不同，不能把两种决策规则混写。

可选软输出为

$$
L_{j,\ell}=
\log\frac{\sum_{a:b_\ell(a)=0}p_{T,j,a}}
{\sum_{a:b_\ell(a)=1}p_{T,j,a}}.
\tag{28}
$$

当前研究不接入信道译码器，不能将这些输出描述为已经完成外信息迭代或编码增益验证。

### 3.7 联合层的执行顺序

#### 3.7.1 明确迭代时序

$$
(H_t,p_t)
\longrightarrow(\mu_t,v_t,r_t)
\longrightarrow F_t
\longrightarrow E_{t+1},H_{t+1}
\longrightarrow y_{D,t+1},b_{t+1},q_{t+1}
\longrightarrow p_{t+1}.
\tag{29}
$$

当前软状态用于修正 CSI，修正后的 CSI 用于产生下一软状态。不能使用本轮尚未计算出的 $p_{t+1}$ 修正 $H_{t+1}$，也不能在同一轮混用不同版本的 $H$。

#### 3.7.2 完整前向算法

~~~text
输入：y、H0、公开导频xK、物理位置、掩码、RF方差、单位协方差C
参数：共享修正网φ、T组均衡参数θt、T个阻尼参数βt

计算修正网固定尺度s、sH，读取C对角；full模式获取匹配C的Cholesky因子
E0 ← 0
数据概率p0 ← [1/4, 1/4, 1/4, 1/4]
μ0 ← xK，v0 ← 数据掩码

对 t = 0, …, T−1：
    Ht ← H0 + BandScatter(Et)
    若训练阶段B：仅对进入下一计算的软反馈状态停止梯度
    rt ← y − Ht μt
    Ft ← 按真实(k,k+d)构造逐元素特征、共轭乘积与掩码
    Dt, gt ← 三层共享CSI修正网络(Ft)
    Et+1 ← Et + sigmoid(βt) sH gt ⊙ Dt ⊙ 有效性掩码
    Ht+1 ← H0 + BandScatter(Et+1)
    yD ← y − Ht+1 xK
    计算当前H下的全局匹配滤波、正规作用及加权列能量
    执行预条件Richardson子步，构造每载波14维特征并截取物理窗口
    拼接唯一中心的logits，与QPSK距离logits相加后生成全局概率
    μt+1, vt+1 ← 概率到星座矩的转换
    记录本层预测和用于监督的带状状态

输出：最终概率、软均值/方差、带状修正，以及可选逐层诊断
~~~

阶段 A 关闭 CSI 增量但仍执行所有均衡层。阶段 B 和 C 使用同样的前向顺序，差别仅在训练参数、损失和梯度边界。

#### 3.7.3 初始状态能够提供什么

首轮数据 $\mu_0=0$，故数据列的 $r_0\mu_0^*$ 为零。首轮修正依赖原始 CSI、接收残差、已知导频和学习先验；不能声称首轮已经利用了可靠的数据判决。

首轮完整残差为 $y-H_0x_K$，其中仍包含未知数据贡献。网络必须在训练中学会区分这种贡献与可修正误差，而不能把首轮残差视为纯信道误差。

### 3.8 三阶段训练与联合损失

#### 3.8.1 损失的归一化

设批次含 $M$ 个 D 块，数据集合固定。逐层分类损失为

$$
\mathcal L_{\rm CE}
=-\frac{1}{MTN_D}\sum_{m=1}^{M}\sum_{t=1}^{T}
\sum_{j\in\mathcal D}\log p_{m,t,j,c_{m,j}}.
\tag{30}
$$

仅全局中心输出参与该损失，重叠上下文不重复计数。

逐层 CSI 损失为

$$
\mathcal L_H
=\frac{1}{MT}\sum_{m,t}
\frac{\|H_{m,t}-H_{{\rm ref},m}\|_F^2}
{\max(\|H_{{\rm ref},m}\|_F^2,\epsilon_H)}.
\tag{31}
$$

使用线性 NMSE，不在损失内部取 dB。所有层等权，避免改变 $T$ 时无意放大损失。研究默认 $\epsilon_H=10^{-30}$，同时对近零参考能量做数据诊断。

联合目标为

$$
\mathcal L_C=\mathcal L_{\rm CE}+\lambda_H\mathcal L_H.
\tag{32}
$$

$\lambda_H$ 是任务权衡，不是 CSI 物理方差。CSI 为辅助监督，不能依据测试 BER 反向选择它。

#### 3.8.2 阶段 A：固定 CSI 的均衡器预热

设置 $E_t=0$，仅训练均衡层及其隐藏映射，目标为 $\mathcal L_{\rm CE}$。初始化仍是均匀概率，不引入额外 ZF 或真值符号初值。

该阶段解决“修正网预训练时均衡器尚未学会生成软判决”的启动问题。它不改变最终推理结构，也不在推理前额外运行一整套预热网络。

完成均衡器预热后，将其参数用于阶段 B。改变展开深度或均衡内核时，应重新建立匹配的预热状态。

#### 3.8.3 阶段 B：修正网络的 CSI 监督预训练

冻结全部均衡参数，训练共享修正网和阻尼参数，目标为 $\mathcal L_H$。

每批重新执行完整当前 $H_t$ 轨迹，均衡器输出为真实预测，不用发送符号替代，也不把固定 $H_0$ 下的一组预测缓存供所有轮次使用。

在进入下一轮时，对传给修正网和均衡器的软均值、软方差 $\mu_t,v_t$ 停止梯度；**不对 $E_t,H_t$ 的修正递推停止梯度**。梯度仍沿连续的信道状态路径传播，但不通过“较早信道—均衡软判决—较晚修正输入”这条路径回传。

冻结参数与停止梯度不是同一操作。当前阶段仅使用 CSI 损失，已截断的检测反馈路径不需要梯度；若将来在阶段 B 加入检测损失，就必须保留检测输出对当前 $H$ 的导数，不能将整段均衡器无条件放在无梯度环境中。

#### 3.8.4 阶段 C：联合微调

解除均衡参数冻结和软反馈停止梯度，使用式（32）。由修正后的 $H$ 影响当前及后续检测，检测损失也可以调整修正网络。

不使用 teacher forcing：任何阶段都不将真实 $x_D$ 输入前向反馈。训练时读取标签以计算损失，与将标签输入算法是不同操作。

阶段 C 仍不能保证网络输出的 $H$ 恰好是真实信道；它是在物理监督和检测目标共同约束下学习的 CSI 估计。

#### 3.8.5 训练设计的作用

阶段 A 先建立有意义的软检测能力；阶段 B 让修正网络在实际模型反馈下学习信道估计；阶段 C 再协调检测目标与 CSI 目标。三阶段都沿用相同的均匀初始化和层内顺序，避免训练使用真实符号反馈而推理只能使用预测反馈的差异。

NOF1 与 NCS1 分别学习参数，各自覆盖全部研究 SNR，D1/D2 共用模型。两信道修正半带宽统一固定为 $B=16$，由 `model.bandwidth` 唯一配置。验证集先搜索 $\lambda_H\in\{0.01,0.1,1\}$，再搜索 $T\in\{4,8,12,22\}$，选定后仅用种子20261028重训并评测，由 `selection.seeds=[20261028]` 配置。参考 CSI 不进入推理，测试数据不参与参数学习或结构选择。


### 3.9 参数规模与计算复杂度

#### 3.9.1 三层修正网的参数量

输入通道 $C_F=14K+5$，隐藏宽 $h_c=32$，输出通道 $3K$。计入偏置：

$$
P_{\rm corr}
=(3C_Fh_c+h_c)+(3h_c^2+h_c)+(3Kh_c+3K)
=1443K+3616.
\tag{33}
$$

当 $B=16,K=33$ 时，$P_{\rm corr}=51\,235$。共享意味着该参数量不乘 $T$，但调用次数和运算量仍乘 $T$。

忽略边界节省、激活和偏置，单层次修正调用的实数乘加数约为

$$
\operatorname{MAC}_{\rm corr}
=N(3C_Fh_c+3h_c^2+3Kh_c)
=N(1440K+3552).
\tag{34}
$$

当 $N=1024,B=16$ 时约为52,297,728 MAC，比旧564通道修正网减少约15.4%。若把一次 MAC 计为两次 FLOP，必须明示口径，不能与复数运算的 FLOP 混加而不说明。

#### 3.9.2 均衡层的参数量

第3.6节的输入为 $14W$，隐藏维度 $h_e=48$，中心输出 $4S$，加上步长、温度和不确定度三个标量，则每层

$$
P_{\rm eq}=h_e(14W+1)+4S(h_e+1)+3.
\tag{35}
$$

$W=32,S=16$ 时为24,691。计入 $T$ 个 CSI 阻尼参数：

$$
P_{\rm total}=P_{\rm corr}+T P_{\rm eq}+T.
\tag{36}
$$

默认8层配置对应248,771个可训练参数，已与当前模型 CPU 实例化计数核对。该数值不包含不可训练的信道、协方差和掩码。

均衡神经映射每层成本约为

$$
N_w[14Wh_e+4Sh_e],
\tag{37}
$$

$N_w=\lceil N/S\rceil$ 为完整物理网格的窗口数，默认64；仅数据位置计入分类损失。它与修正网的全行卷积是两种不同的空间共享结构。

#### 3.9.3 完整信道与有色噪声算子

完整基础 $H_0$ 的稠密矩阵与向量乘法为 $O(N^2)$，带状增量为 $O(NK)$。每层需要完整残差、导频贡献、匹配滤波及正规算子作用，还包括两类 $\mathcal W$ 向量作用。

对角模式的噪声逆作用为 $O(N)$。完整模式对稠密 $C$ 的一次固定 Cholesky 准备为 $O(N^3)$，每次向量求解为 $O(N^2)$；协方差固定时可摊销分解成本。两种模式的完整稠密信道作用均保留 $O(N^2)$ 成本。

正文算法每层量级为

$$
O\!\left(
N^2+NKh_c+Nh_c^2+N_wWh_e
\right),
\tag{38}
$$

其中常数必须通过实际算子调用次数统计。不能将其简写为 $O(NB)$，也不能忽略 CSI 重建和输入搬运。

DPSS 到稠密频域 CSI 的重建还涉及时间基作用和 FFT 变换，属于输入准备成本。稠密实现可按 $O(NQL+N^2\log N)$ 量级估计；`dense` 在 CPU 双精度重建，训练路径 `dense_device` 在设备双精度重建后转为模型精度，二者后续均执行完整稠密均衡。实验性 `dpss` 算子直接作用的等价边界及精度诊断见 [DPSS 后端说明](dpss_backend.md)。

### 3.11 算法的适用条件与性质

该算法面向已获得接收观测、初始 CSI、公开导频及噪声参数的频域均衡问题。它不在内部完成波形同步或多普勒参数估计；这些前端处理的结果及剩余失配通过初始 CSI 和接收观测影响算法。

可以由结构直接确定的性质包括：完整初始耦合保留；只有指定带内元素发生修正；导频与空槽符号固定；数据概率归一化；修正网络跨层共享参数；无须逐层对信道正规矩阵求逆。

需要通过研究验证的性质包括：软反馈能否改善 CSI；预测方差能否反映实际错误；修正能否降低 BER；更多迭代是否持续有效。由于更新方向由非线性网络学习，同一接收观测被反复使用，门控与阻尼均不构成全局收敛或逐层单调改善的证明。

本算法的核心在于让结构化 CSI 修正与 MMSE 深度展开构成受监督约束的闭环：物理模型组织观测信息，学习模块补充误差先验，软判决连接相邻迭代，联合损失使信道解释与检测目标共同参与优化。

# EPNet 实现与 WATERMARK 数据适配

依据用户提供的 Zhang 等《Meta Learning-Based MIMO Detectors: Design, Simulation,
and Experimental Test》，IEEE TWC 2021，DOI `10.1109/TWC.2020.3030882`。
本项目实现未编码 QPSK 的独立 EPNet 检测器及论文 III-C 的 LSTM 优化器。
当前数据没有 turbo 编码与译码反馈，因此不实现 TurboNet / 多 JDD 接收机。

当前仅保留 EPNet 实现、数据适配、训练代码及默认训练配置，不进行训练或测试。
EPNet 专属测试文件、运行产物及接入算法对比的配置和流水线已清理。

## 公式对应

`src/algorithms/epnet/model.py` 实现实值 EP 展开，默认 5 层，每层一个标量
`beta`，实际阻尼为 `sigmoid(beta)`，与载波数量无关。

| 原文 | 实现 |
| --- | --- |
| (8)、(9) | 自然参数 `precision=Lambda`、`natural=gamma`；Cholesky 解高斯后验与边缘方差 |
| (10) | 逐坐标 cavity，用 `diag(Sigma)` 的倒数消除当前站点 |
| (11) | 在实值 QPSK 星座 `[-1,+1]/sqrt(2)` 上精确求矩，使用等价的稳定 tanh 公式 |
| (12)、(14) | 拒绝非正/非有限精度建议，保持旧站点；对自然参数进行 sigmoid 阻尼 |
| (4) | 最后一层 cavity 生成逐比特 `log(P(0)/P(1))`，对应项目的实部/虚部比特顺序 |
| (20) | 所有层 cavity 均值的平方误差，按实坐标求和，按层数及样本数平均 |

默认最小方差 `1e-8`，初始阻尼 `0.1`。默认初始 `gamma=0`、`Lambda=0.5`，
逐字采用原文 (8) / III-B 的 `Lambda=1/(2*Es)`，本项目 `Es=1`。
该初始化与单位能量 QPSK 的实部方差 `Es/2` 不一致：若采用矩匹配，精度应为
`2/Es=2`。配置开放 `initial_precision`，可显式设置为 2 做对照；默认保留原文写法。
原文 (10) 排版使用矩阵符号，但 cavity 定义是边缘分布比值，因此必须使用边缘方差，
不能把完整协方差的矩阵逆当成逐坐标边缘精度。

严格依照图 2 及 III-B，网络返回第 L 层**站点更新前**的 cavity。
因此 `(20)` 对最后一个阻尼参数的梯度为零，L 个登记参数中只有前 L-1 个影响输出。
实现没有追加一次线性求解来让最后一个参数生效。
既有 `src/algorithms/ep/real.py` 使用另一篇论文的站点均值/方差阻尼及更新后均值输出，
其算法和默认参数保持不变，不应把二者的差异全部归因于学习本身。

## 数据与监督

配置中的 NOF1 与 NCS1 路径对应现有 compact-v2 数据。每个 D1/D2 块使用全部
1024 个接收频点、512 个数据列，完整保留 ICI：

`y_data = y_D - H_est @ known_D`，`H_data = H_est[:, data_indices]`。

使用完整复有色热噪声协方差白化；实值似然保留复协方差虚部的交叉块，并使用正确的
因子 2（复噪声实部/虚部方差是复方差的一半）。EPNet 不学习信道矩阵、不膨胀噪声，
也不使用参考 CSI 作为输入或训练目标。检测接口不接收标签；监督符号只在独立损失计算时读取。

现有 compact-v2 的 `H_est` 是文档已说明的参考辅助构造 CSI。
本实现直接使用与四个基线相同的既有输入，不生成新补偿、搜索 DPSS 或改变数据。
所以最终结果属于当前构造数据条件，不能解释成未经参考辅助的原始接收机估计性能。

训练仅打开 `train.h5`、`validation.h5`、`model.h5`，检查记录不重叠、共享模型身份和
SNR 一致。训练集符号计算梯度，验证集公式 (20) 损失选择最佳检查点（包含未训练初始值）；
测试文件不参与拟合、选轮次或元优化器训练。按用户要求，NOF1、NCS1 分别训练，
每个信道把全部 7 个 SNR 的训练样本联合用于一个 EPNet，所有 SNR 与 D1/D2 共用
同一组阻尼。梯度先在所有 SNR/样本上求平均，再更新一次参数；验证也使用所有 SNR
的整体平均损失选择一个最佳模型。测试必须匹配信道、共享数据模型、协议、载波数和 SNR。
检查点升级为 `watermark-epnet-joint-snr-v2`，拒绝旧的逐 SNR 模型，防止误用。

## LSTM 训练与内存

`src/training/meta_optimizer.py` 实现论文 (16)--(19)：标准正态 `W,q` 组成新二次任务，
每任务优化变量初始为 1。不同坐标共用两层、每层 5 单元的 LSTM 权重，隐藏状态相互独立。
对输入梯度执行 detach，对应图 3 虚线，不计算二阶导；最终任务损失按 `J*L` 归一化，
用 Adam 更新元优化器。默认 100 epoch、20 任务、20 步、学习率 `1e-3`。

元优化器随后冻结，用真实接收链训练样本优化 EPNet。每次更新流式累计**全部 SNR、
整个训练集合**的公式 (20) 梯度，最后才改变一次阻尼。
这保留了论文目标和大批量更新语义，避免同时保存数千个 1024 维矩阵的自动微分图。
默认物理微批大小为 4，验证与训练均流式读取，不缓存几十 GB 的似然矩阵。
数据样本取代论文模拟生成的 5000 个 MIMO 标签，这是水声数据适配的明确差异。
固定数据上的训练不是完整的在线信道变化触发系统。

保留的配置为 20 epoch、每 epoch 一次全量联合更新，不限制帧数；元优化器配置为
100 epoch / 20 任务 / 20 时间步。这些仅是代码默认值，不表示存在已完成的实验。

可以用 `optimizer=adam` 做论文 Fig.4 的传统优化器对照，默认学习率 `0.1`，每 epoch
执行一次全训练集梯度更新。LSTM 的更新幅度由预训练权重决定，`learning_rate` 仅对 Adam 生效。
不保证少量 smoke 训练能达到论文或完整训练的 BER 收益。

## 保留的代码与配置

PyTorch 依赖由 `pyproject.toml` 的 `learning` 可选依赖提供。

| 路径 | 用途 |
| --- | --- |
| `src/algorithms/epnet/` | 网络、外信息输出、检查点格式与独立检测适配 |
| `src/data/epnet.py` | 完整矩阵似然与独立监督符号的流式读取 |
| `src/training/epnet.py` | 每信道全 SNR 联合目标、验证选择与续训逻辑 |
| `src/training/meta_optimizer.py` | LSTM 元优化器 |
| `scripts/train/epnet.py` | 独立训练入口代码 |
| `configs/training/epnet.json` | 训练默认配置 |

保留的设计仍为 NOF1/NCS1 分别训练，每个信道的全部 SNR 共用一组参数。

## 对比算法范围

当前对比仅包含 Single-tap MMSE、Full-matrix LMMSE、EP、Robust EP。
EPNet 没有注册到对比算法列表，比较入口、报告和绘图不提供 EPNet 分支。
其独立实现不触发训练、评测或后台任务。
